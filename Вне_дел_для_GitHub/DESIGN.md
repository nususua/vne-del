# Дизайн · Вне дел

## Направление

Спокойная редакционная подача: крупная типографика, фотографии занятий и округлые элементы управления. Изначальный референс сохранён в submission; итоговая корректировка пользователя — чёрная палитра вместо зелёной и круглые плашки.

## Палитра

Основной фон #101010, поверхность #181818, дополнительная #222222. Текст #f4f2ed, вторичный #b5b3af, граница #383838. Светлая кнопка на тёмном фоне. Для фокуса #e1b6ff. Акценты карты интересов — приглушённые лиловый и тёплый коричневый. Светлая тема доступна переключателем.

## Типографика и сетка

Georgia — заголовки, Arial/Helvetica — интерфейс. Максимальная ширина 1320 px, боковые поля 4–5%. Карточки: 4 колонки на широком экране, 3 до 1100 px, 2 до 680 px. Мобильные формы не требуют горизонтальной прокрутки; лента плашек прокручивается отдельно. Карточки 4:5, изображения с object-fit: cover, полная иллюстрация в карточке идеи.

## Компоненты

Bootstrap 5.3.3 локально: модальные окна, формы, уведомления. Кнопки и фильтры — плашки с полным скруглением; фотографии со скруглением 18–24 px; окна 23–28 px. Основные области нажатия от 44 px. Активный пункт навигации заполнен контрастным цветом. Профиль содержит свои публикации и публичную гостевую книгу, владелец может редактировать имя, город и биографию.

## Состояния и доступность

Фокус с клавиатуры, подписи полей, доступные названия и aria-pressed для сохранения/выбора интересов. Есть состояния пустой доски, пустой выдачи, отправки письма, ошибки сети и повторного сохранения. Код и заметки выводятся с экранированием HTML. Анимации умеренные; prefers-reduced-motion отключает их. Модальные окна без fade для предсказуемого переключения.

## Честные тексты

Главный экран описывает пользу без постоянных учебных подписей. Ограничения стартовой коллекции раскрыты в «О сервисе». Публичные комментарии не названы личными сообщениями. Нет выдуманных счётчиков активности или обещания записи на занятия.

Быстрые плашки «Есть 15 минут» и «Без затрат» меняют соответствующий фильтр и отражают выбор. «Удиви меня» открывает одну идею из текущей выдачи и недоступна при пустом результате. Порядок: для вдохновения, сначала быстрые, доступные или по названию. Удаление с доски можно отменить в уведомлении с восстановлением статуса и заметки. Черновики публикаций восстанавливаются в текущей вкладке.

Основная форма для сдачи: выбор одного из трёх локальных профилей и код 1234. Под формой явно объяснена имитация входа и локальное хранение. Постоянная строка режима помогает не спутать локальные данные с облачной синхронизацией.
