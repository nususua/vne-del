# Выбранный референс

Анна выбрала Pinterest как ориентир для визуальных досок. Файл reference-pinterest.png — опубликованный снимок настольного интерфейса из разбора IXD@Pratt, 2024.

Источник: https://ixd.prattsi.org/2024/01/design-critique-pinterest-desktop-version/

Из референса использованы фотокарточки, короткие подписи, сохранение идеи и переход к подробностям. В финальной версии прототипа — собственная зелёная палитра, тёмная и светлая темы, карта интересов, подбор по времени/бюджету/месту и личный прогресс. Карточки выровнены в сетку по строкам, с едиными пропорциями обложек; точного копирования Pinterest не заявляем.

Первая версия появилась по словесному ориентиру Анны; опубликованный снимок был найден и включён при подготовке пакета. Пять присланных позднее изображений использованы как референсы отдельных хобби, их происхождение описано в ASSETS.md. Они не заменяют основной снимок концепта.
