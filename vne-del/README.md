# Вне дел

От интереса — к первой попытке. Выбирай занятие по времени, месту и бюджету, сохраняй на доску и отмечай, что получилось.

## Локальный запуск

На macOS открой START.command. На любой системе из папки приложения: `python3 -m http.server 5174 --bind 127.0.0.1` (Windows: `python -m http.server 5174 --bind 127.0.0.1`). Затем перейди на http://127.0.0.1:5174/. Нужен Python 3. Сборка и установка пакетов для приложения не требуются. Bootstrap хранится в vendor. Исходная версия hobby-board работает отдельно на порту 5173.

## Вход и данные для сдачи

Основной режим автономный: без регистрации во внешних сервисах и без отправки писем. Нажми «Войти», выбери Анну, Соню или Мишу и введи проверочный код **1234**. Это прототип авторизации, а не защита настоящих персональных данных.

Все профили, доски, статусы, заметки, идеи и открытые записи сохраняются в localStorage этого браузера. После обновления страницы и повторного запуска сервера данные остаются. Выход завершает сеанс, но сохраняет доску. При выборе другого профиля открывается его собственная доска; публикации общие. На другом устройстве этих данных нет. Очистка данных сайта удалит сохранения.

## Дополнительный режим почты

Настоящий вход через Supabase сохранён как дополнительная интеграция. Он не требуется для основной сдачи и пока не проверен полностью. Открой http://127.0.0.1:5174/?mode=cloud только после настройки:
1. Создай проект Supabase и выполни backend/schema.sql один раз.
2. Скопируй config.example.js в config.local.js, укажи URL проекта и публичный publishable key. Секретный ключ и пароль базы сюда не подходят.
3. Настрой Site URL и разрешённый Redirect URL для http://127.0.0.1:5174/?mode=cloud.
4. Для отправки произвольным адресатам нужен собственный SMTP. Штатная почта ограничена участниками команды и малым числом писем.

Без параметра mode=cloud приложение работает локально даже без config.local.js. Данные двух режимов раздельные.

## Основной сценарий

Вход (профиль и код 1234) → выбор интересов → подборка → карточка с материалами и первым шагом → сохранение → «Моя доска» → статус и личная заметка → обновление страницы и проверка результата. Второй сценарий: создание идеи → общая лента → открытие другим участником → сохранение на его доску.

## Файлы

- DESIGN.md — оформление и состояния интерфейса.

## Проверка правил данных

Если установлен Node.js: node --test tests/*.test.cjs. Само приложение Node.js не требует.

## Репозиторий и сдача

Не включай config.local.js, .env, секреты, пользовательские данные и зависимости. Публичные параметры для своего проекта заполняются по примеру (config.example.js, .env.example). Открытый репозиторий заменяет архив; видео прикладывается в форме сдачи.
